## นำเข้า Canva (ต้องทำเอง)
ระบบไม่อนุญาตให้ผู้ช่วยอัปโหลดไฟล์ที่ AI สร้างเข้า Canva โดยตรง จึงยังไม่มีงานออกแบบใน Canva ให้ทำตามขั้นตอนนี้
1. เปิด Canva แล้วไปที่ Create a design → Import file (หรือลากไฟล์ลงหน้า Home)
2. เลือก `slides_updated_th.pptx` Canva จะแปลงเป็นงานนำเสนอที่แก้ไขได้ และบันทึกผู้บรรยายจะอยู่ใน Notes
3. ตรวจฟอนต์: ไฟล์ใช้ Sarabun ซึ่งมีใน Canva ถ้าตัวอักษรไทยเพี้ยน ให้เลือกข้อความทั้งหมดแล้วเปลี่ยนเป็น Sarabun
4. ภาพกราฟเป็นภาพจากข้อมูลจริง ห้ามแก้ตัวเลขบนภาพ ถ้าต้องวาดใหม่ให้ใช้ CSV ใน `figures/data/` ของ bundle
5. แก้ "ผู้จัดทำ: รอระบุ" ในสไลด์แรกและหน้าปกรายงาน

## สิ่งที่ผู้จัดทำต้องทำก่อนส่ง
